## Sprint 4 priorities

   startup output, Selenium report and any failure screenshots. Never package
   PostgreSQL while it is running or omit empty database directories.
2. **Six meaningful workflows:** match usability task IDs to Selenium tests.
   Assert changes in counts, persistence, error prevention, manager filters and
   history. A successful sign-in alone does not prove a counting workflow.
3. **Real user evidence:** independently recruit three people outside class.
   Capture outcomes, timing, assistance, quotes and every observed issue.
4. **Visible leadership:** bring a ranked findings list, explain impact,
   compare overlapping reports, and help the team agree on 8–10 issues.
5. **Reviewable issues:** write reproducible bugs or clear feature requests
   with evidence and acceptance criteria; link each back to observations.
